# UI 说明：应答

- **谁在什么时刻打开**：给小客服团队的可交接分诊台。
- **首屏任务句**：这单，该谁接。
- **主操作**：按「工单入队 → 查库起草 → 转人工交接」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：调度席；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：调度席。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给小客服团队的可交接分诊台：按紧迫度、业务线和待办分队列，草稿逐条引用知识库；退款承诺、权限或缺失依据自动转人工。
